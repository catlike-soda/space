## 📖 使い方

**🔍 単語検索**
1. 検索タブを開く
2. `한국어 → 日本語` か `日本語 → 한국어` を選択
3. 単語を入力 → 結果をタップ → 詳細表示
4. 「活用形」「例文」「関連語」タブ切替

**📝 文章分析**
1. 「文章」タブを開く
2. 韓国語の文章を入力（例：`저는 학교에 갔어요`）
3. 「文章を分析」をタップ
4. AIが文法ポイント + 翻訳を表示

**🌐 言語切替**
`設定 ⚙️` → `表示言語` → **日本語** / **中文**

## 📖 使用方法

**🔍 查词**
1. 打开搜索标签
2. 选择 `한국어 → 中文` 或 `中文 → 한국어`
3. 输入词 → 点击结果 → 查看详情
4. 切换「活用形」「例句」「关联词」

**📝 句子分析**
1. 打开「文章分析」标签
2. 输入韩语句子（如 `저는 학교에 갔어요`）
3. 点「分析句子」
4. AI 拆解单词 + 语法标注 + 翻译

**🌐 切换语言**
`设置 ⚙️` → `表示言語` → **中文** / **日本語**
